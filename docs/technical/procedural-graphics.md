# Procedural graphics

Two Canvas 2D surfaces produce the living part of the desktop. Neither uses WebGL.

## Cortex Mapper

- Nodes are generated by `generateSynapseData(width, height)`: twelve discipline labels placed on a ring around the canvas center, with jittered radius and radius-as-size.
- A `ResizeObserver` rebuilds the node field when the window body changes size. That *does* re-roll radii (intentional: the cortex is not a stable specimen).
- Animation: `t += 0.02` per frame. Each node is offset by `sin(t + i) * 3`. Edges exist when distance `< 200` and their alpha is a further sine.
- Persistence: `fillRect` with `rgba(10,10,20,0.15)` instead of `clearRect`. The smear is the “neural afterimage.”
- Active node is stored in a ref so highlighting does not restart the rAF subscription.
- Twenty extra dots are hashed out of sines — decoration, not a particle system with state.

## Knowledge Graph

- Sixteen labeled nodes in four categories (Philosophy, Science, Art, Tech), from `graphCategories`.
- Intra-category edges at p=0.6; eight additional cross-category edges.
- Forces each frame:
  1. weak pull to canvas center
  2. pairwise Coulomb-style repulsion
  3. mouse attraction inside 80px
  4. velocity damping `* 0.95`
  5. box clamp with a 20px margin
- Hover is distance `< 16px` against the mouse ref, evaluated inside the rAF loop. It must **not** live in React state: an earlier version listed `hoveredNode` as a `useEffect` dependency and re-seeded the whole graph on hover.
- Same alpha-fill persistence as cortex, slightly more opaque (`0.2`).

## What this is not

- Not a knowledge graph over a real corpus.
- Not a physics engine (no mass, no integrator beyond Euler with damping).
- Not resolution-independent: Graph uses a fixed 360×260 backing store stretched by CSS. Cortex is the one that matches backing store to element size.

## Cost

At 60fps, two loops × 16–12 nodes is trivial. The important part is **not running them when minimized** — `DraggableWindow` returns `null` if `minimized`, which tears down the effect and cancels rAF.
